# Getting help

Start with the [README](README.md), [configuration and troubleshooting](docs/configuration.md), and [known limitations](docs/limitations.md).

For usage questions, open a [GitHub issue](https://github.com/ttadev24/FreshMesh/issues) with your goal, the command you ran, your operating system, Python/Node versions, commit hash, and sanitized error output. English and Vietnamese questions are welcome. Use the bug template for reproducible failures and the feature template for proposals.

Do not include credentials, private datasets, or database dumps. Report suspected vulnerabilities through [SECURITY.md](SECURITY.md). Community conduct concerns follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

Support is provided by volunteers on a best-effort basis. There is no guaranteed response time or commercial support service.
